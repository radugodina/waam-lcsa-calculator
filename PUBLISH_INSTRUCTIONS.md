# Publish to GitHub Pages

1. Sign into `https://github.com/radugodina`.
2. Create a new **Public** repository named `waam-lcsa-calculator`, with `main` as its default branch.
3. Add the contents of this package to the root of the repository (`index.html` and `README.md` must be at the top level). Do not upload the ZIP as a single file.
4. Under repository **Settings → Pages**, set the source to **Deploy from a branch** and select `main` and `/(root)`, then save.
5. Check deployment status and visit `https://radugodina.github.io/waam-lcsa-calculator/`. The README already contains the link users can click.

The scientific calculator works as a self-contained index.html. The PNG assets are provided separately as convenient copies; logo data is embedded in the HTML as well.
